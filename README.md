# Práctica Git y Java

## Mi primer programa en Java

En esta práctica creamos nuestro primer programa utilizando Java.

## Código utilizado

El programa muestra el mensaje:

Hola, mundo!

## Preguntas y respuestas

### 1. ¿Qué función cumple main?

El método main es el punto de entrada del programa. Java comienza la ejecución del programa desde este método.

### 2. ¿Qué diferencia existe entre javac y java?

javac sirve para compilar el código Java y generar el archivo .class. En cambio, java sirve para ejecutar el programa compilado.

### 3. ¿Qué archivo se genera después de compilar?

Después de compilar se genera el archivo Main.class.

### 4. ¿Por qué el archivo se llama Main.java?

Porque contiene una clase pública llamada Main. En Java, el nombre del archivo debe coincidir con el nombre de la clase pública.

### 5. ¿Qué ocurre si la clase se llama Programa pero el archivo se llama Main.java?

Se produce un error de compilación porque el nombre del archivo debe coincidir con el nombre de la clase pública.
